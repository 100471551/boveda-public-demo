# Bóveda Alpha 1.0.2

Initial production-ready public demo release.

- Static, fail-closed runtime for GitHub and Vercel.
- Three sanitized pre-analysed project snapshots.
- Read-only dashboards, Findings, History, diagnostics and evidence trails.
- Pre-generated HTML and PDF report downloads.
- Import, new analysis, deletion and reanalysis protected by explanatory demo notices.
- Privacy validation for source snapshots and built artefacts.
- GitHub deployment checks and Vercel build/security configuration.

The analytical backend, local project storage, source-project directories and provider credentials are not part of the deployed runtime.
